Convert the asset-request document I provide into the exact JSON structure
required by AI Asset Provenance Helper.

OUTPUT RULES

1. Output ONLY valid JSON.
2. Do not wrap the JSON in Markdown code fences.
3. Use exactly this top-level structure:
   {
     "manifestVersion": 2,
     "assets": [...]
   }

4. Every requested asset must become exactly one object in "assets".

5. Every asset object must contain these four properties:
   "filename"
   "resolution"
   "alpha"
   "prompt"

6. Do not add any other properties.

7. "filename":
   - Use only the final leaf filename.
   - Never include a folder path.
   - Example source:
     assets/ui118/backdrops/loc_gas_station/day.webp
   - Required output:
     day.webp
   - Animation source documents may use the exact sequence token `{frame:03d}`.
     Keep that token in the manifest; on import the helper safely represents it
     as `_frames` in its Windows folder name while preserving the complete
     sequence instruction in the prompt.

8. "resolution":
   - Normalize to WIDTHxHEIGHT.
   - Example:
     1920x1080

9. "alpha":
   - If the source explicitly requires transparency / true alpha: "required"
   - If the source explicitly specifies an opaque backdrop / full background: "not_required"
   - Otherwise: "unknown"
   - Do not guess!

10. "prompt":
    - Copy the complete generation prompt.
    - Do not summarize it.
    - Do not improve it.
    - Do not rewrite it.
    - Do not translate it.
    - Do not shorten it.
    - Do not omit any line or technical specification.
    - Preserve the prompt's content exactly, using valid JSON escaping.
    - If a prompt contains FLOWMETA and/or PROZESSMARKER, preserve those clauses
      verbatim inside "prompt". They are workflow instructions for the helper,
      not new JSON properties and not text to be summarized or normalized.

11. Do not omit any requested asset.

12. Do not invent information that is missing.

13. The order of assets should remain the same as in the source document.
